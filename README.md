# Daily Smiles Dental: website redesign (demo)

Open `index.html` in a browser, or upload this folder to any static host.

```
index.html          structure and copy
css/styles.css      all styling and animation, in numbered sections
js/main.js          "I'm here because" picker, payment tabs, FAQ, live hours, motion
assets/images/      put real clinic photos here (none are used yet)
```

Edit services in `WHY`, payment copy in `PAY`, questions in `FAQ` and hours in `HRS`, all in `js/main.js`.
Links go to the clinic's existing site until the new pages are built.
